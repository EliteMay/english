# English Structure Lab

英語を日本語訳の暗記ではなく、**文の構造・本質・核イメージを基礎から積み上げて理解する**ための個人学習サイトです。

友人作成の以下の教材構成を出発点にしています。

- 英語文法ワークシート①: S / V / O と文の骨格
- 英語文法ワークシート②: 5文型
- 英語文法ワークシート③: 動詞の語法、長い英文の骨格、修飾
- 英語文法ワークシート④: 時制、完了形、長文の時制分析

教材PDFそのものはリポジトリへ含めず、内容の学習方針をWeb向けに再構成しています。

## 目的

1. 数学で基礎を1つずつ積み上げるように英語を理解する
2. 基礎から始めるが、説明を幼く・薄くしない
3. 長文では訳す前に S / V / O / C / M と節構造を取る
4. 前置詞・基本語は日本語訳の丸暗記より核イメージを優先する
5. 最終結果だけでなく、**途中でどう考え、どう間違え、どう修正したか**を記録する
6. 学習記録をJSONでChatGPTへ渡し、次の教材やサイトを本人向けに調整する

## 崩してはいけない仕様

- 正答率だけを学習評価にしない
- S/Vを最初に固定する読解方針を維持する
- 長文で途中のラベル変更履歴を保存する
- 最初の解釈、迷った点、修正した考えを別々に保存する
- ペンタブの自由書き込みを保存する
- ChatGPT提出JSONに途中経過を含める
- 基礎説明を「子ども向けの簡略説明」へ落としすぎない
- 単語・前置詞は可能な範囲で核イメージから扱う

## 主な機能

### 理解ロード

`文の中心 → S/V → Vの後ろ → 5文型 → 動詞 → 修飾 → 時制 → 核イメージ → 節 → 長文`

の順に理解を積み上げます。理解チェックで正答率を記録し、理解済み項目は飛ばしやすくします。

### 長文・構造分析

- 英文の各語へ S / V / O / C / M を付ける
- ラベルを変更した履歴を時系列保存
- 自信度を1〜5で記録
- 「最初にどう読んだか」
- 「どこで迷ったか」
- 「読み直して何を変えたか」
- 読み直し時点のスナップショット保存
- 構造確認結果を保存

### ペンタブ

Pointer Events を使用しています。

- ペン入力
- 筆圧による線幅
- 黒 / 赤 / 青 / 緑
- 消しゴム
- 1ストローク戻す
- 全消去
- ストロークを座標データとして保存

タッチ入力は通常のスクロールに使い、ペン・マウスで書き込む想定です。

### ChatGPT提出JSON

以下をJSONへ書き出します。

- `mastery`: 単元理解度
- `attemptHistory`: 問題の回答履歴
- `reading.annotations`: 現在のS/V/O/C/M指定
- `reading.annotationHistory`: 指定をどう変更したか
- `reading.revisions`: 読み直し時点の状態
- `reading.firstHypothesis`: 最初の解釈
- `reading.confusionMemo`: 迷った点
- `reading.correctionMemo`: 修正内容
- `reading.penStrokes`: ペンタブ入力
- `journal`: 自由な思考メモ
- `eventLog`: 学習中の操作時系列
- `chatgptAnalysisRequest`: ChatGPTに何を見てほしいか

## 起動・利用方法

GitHub Pagesでの利用を前提としています。

`index.html` を `file://` で直接開くと JSON の `fetch()` がブラウザに拒否される場合があります。GitHub PagesまたはHTTPサーバーから開いてください。

## GitHub Pages

静的な HTML / CSS / JavaScript / JSON のみで構成しているため対応しています。

GitHubリポジトリの Settings → Pages で `main` ブランチの `/ (root)` を公開対象にすると利用できます。

## ファイル構成

```text
/
├─ index.html
├─ css/
│  └─ styles.css
├─ js/
│  └─ app.js
├─ data/
│  ├─ curriculum.json
│  ├─ lessons.json
│  ├─ reading.json
│  └─ core-images.json
├─ README.md
└─ 作業報告書.md
```

## データ保存場所

学習記録はブラウザの `localStorage` に保存します。

キー:

```text
english-structure-lab-v1
```

GitHub Pagesへ個人の学習履歴を自動アップロードすることはありません。

## 設定保存方法

現在はテーマ設定と学習履歴を同じローカルデータに保存しています。

別PCへ移す場合は「ChatGPT提出」画面からJSONを書き出し、別端末で読み込んでください。

## 注意点

- JSONには本人が入力したメモや学習途中の履歴が入ります。公開リポジトリへ学習JSONをコミットしないでください。
- 長文の自動判定は初版では主節中心の簡略モデルです。節内部の S / V / O / C を階層的に判定する機能は今後の改善対象です。
- ペンストロークを大量に残すとlocalStorage使用量が増えます。

## 既知の問題 / 今後の改善候補

1. 節内部を `主節 / 関係詞節 / that節 / 副詞節` と階層化してラベル付けする機能
2. ペンで英文を囲んだ範囲と単語ラベルを関連付ける機能
3. ChatGPT分析済みJSONから「次回教材」を取り込む形式
4. 診断テストを増やし、理解済み単元をより正確にスキップする機能
5. 単語核イメージカードを増やす
6. 読解速度・見直し時間など時間データの分析
7. ペン入力の保存容量対策
