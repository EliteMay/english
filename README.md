# English Worksheet Lab

**Version: v0.5.0**  
**Build: 20260830-2**  
**Data Schema: 4 / ChatGPT Analysis Schema: 2 / Submission Package: 2**

英語を **「PDFのような問題用紙へペンタブで直接解く → 自分で答え合わせ → 解いた紙をZIPでChatGPTへ渡す → 読み方の癖・弱点をサイトへ戻す」** 形で学ぶ個人用GitHub Pagesサイトです。

友人作成の文法ワークシート①〜④を出発点にしていますが、単純な言い換え問題を大量に並べるのではなく、**問題ごとに判断ポイントが変わること**を優先しています。

## 目的

- 紙の教材のように、1ページへ複数問題を並べて解く
- 入力フォームではなく、ペンタブで問題文の上へ直接書く
- S/V → O/C・文型 → 動詞 → to/ing・核イメージ → 節 → 時制 → 語順 → 誤文修正 → 長文・段落へ積み上げる
- 基礎から扱うが、同型の簡単問題を大量反復しない
- 長文は訳より先に主節S/V・節境界・修飾・論理関係を見る
- 前置詞や基本語は日本語1語の丸暗記より核イメージを使う
- 最終結果だけでなく、丸・下線・括弧・矢印・消去・書き直し・迷いタグ・時間を残す
- ChatGPTにはJSONだけでなく、実際に解いた紙面PNG入りZIPを渡す
- ChatGPT分析結果を保存し、次の問題選択やサイト改善へ使う

## 画面構成

### 01 問題を選ぶ

- 14問題セット / 188問
- 分野・難易度・進捗で絞り込み
- フリーワード検索
- カリキュラム5段階表示
- 「続きから」
- ChatGPT分析からの次候補

カリキュラム:

4. **構造を使う** — 語順、誤文修正、構造トラップ、総合診断
5. **長文へ統合** — 一文構造、段落の因果・対比・指示語・要約

## 問題セット

1. S/Vを本当に見抜く
2. O/C・5文型を関係で判定
3. 同じ動詞でも構造が変わる
4. to / ing をイメージで理解
5. 前置詞を核イメージで考える
6. 前置詞の核イメージを広げる

8. 時制を時間の見え方で選ぶ

11. 構造トラップ｜Vっぽい形を全部Vにしない

13. 長文を骨格から読む
14. 段落読解｜骨格・指示語・論理を追う

合計 **188問**。

## 02 問題を解く

A4風の問題用紙へ常時ペン入力します。解答モードへの切替はありません。

- 問題文・英文の上へ直接書く
- S/V/O/C用の下線
- 選択肢へ直接丸を付ける
- 記述罫線
- 黒 / 赤 / 青 / 緑
- 蛍光マーカー
- 細 / 中 / 太
- 筆圧対応
- 消しゴム
- Undo / Redo
- ページ全消去 + Undo
- 85 / 100 / 115 / 130%用紙倍率
- 集中モード
- ページ学習時間
- 途中状態スナップショット

タッチ入力はスクロール、ペン・マウスを筆記に使います。

### ペンデータ

座標は問題用紙に対する0〜1の相対値で保存します。筆圧・時刻・問題ID・ツール・太さ・消しゴムも保持します。

## 03 結果・復習

答え合わせ時は問題用紙を動かさず、紙の下に正答基準を表示します。

- ○ 正解
- △ 部分正解 / 不安あり
- × 間違い
- AI確認 — 自由記述・一部長文

△・×では任意で以下を残せます。

- Sを取り違えた
- Vを取り違えた
- 節の境界
- 修飾を骨格に入れた
- O/C・文型
- 時制・時間軸
- to / ing
- 前置詞イメージ
- 語順
- 単語
- 設問読み違い
- 分からなかった
- 自由メモ

結果画面では、最新状態の理解度・分野別成績・学習時間・履歴を表示します。同じ問題を複数回解いた場合、分野別理解度は原則として**最新の判定**を使います。

### ミス復習

過去結果の最新状態で△・×になっている問題だけを自動収集し、一時的な復習セットを作れます。正解できた問題は次回の復習対象から外れます。

## 04 弱点・ChatGPT分析

ChatGPTから返された分析JSONを読み込むと、次を表示します。

- 全体所見
- 弱点 / 原因 / 根拠 / 確信度
- 分野別AI評価
- 読み方の癖
- できているところ
- 次に優先する内容
- おすすめ問題セット
- 問題集そのものへの改善提案
- 過去の分析履歴

返却形式は `data/analysis-return.schema.json` が正本です。

## ChatGPT提出ZIP v2

書き込み・採点がある紙だけを自動収集します。

```text
english_submission_YYYY-MM-DD.zip
├─ papers/
│  └─ 実際に解いた問題用紙.png
├─ manifest.json
├─ paper-index.json
├─ learning-data.json
├─ ink-history.json
├─ questions.json
├─ diagnostics.json
├─ archived-attempts-summary.json
├─ analysis-return.schema.json
└─ ChatGPTに見てほしいこと.txt
```

### 分析優先順

1. `papers/` — 実際の手書き
2. `ink-history.json` — 消しゴムを含む筆記順
3. `paper-index.json` — 紙面と問題番号・自己採点・迷いタグ・時間の対応
4. `learning-data.json` — 過去結果・以前の分析
5. `questions.json` — 問題と正答基準

## 崩してはいけない仕様

1. サイトの中心は「問題を解く」こと。
2. 1問ずつではなく、複数問題が紙面に並ぶ。
3. ペンタブで紙面へ直接書く。
4. 入力フォーム中心へ戻さない。
5. 同じ型の単純問題で問題数を水増ししない。
6. 基礎から始めるが説明・問題を幼くしすぎない。
7. 長文では主節S/V・節・修飾・論理を見る。
8. 単語・前置詞は核イメージを重視する。
9. 実際に解いた紙面をChatGPTへ渡せる。
10. 消した線を含む途中経過を分析材料として残す。
11. ChatGPTは結果だけでなく読み方の癖を分析する。
12. ChatGPT分析結果をサイトへ戻せる。
13. 学習データを公開GitHubへ自動送信しない。
14. APIキー・秘密情報を公開リポジトリへ入れない。
15. 破壊的操作では復旧手段を優先する。
16. GitHub Pagesの相対パスを維持する。

## 未確認 / 既知の課題

- Windows実機ペンタブでの長時間筆圧・遅延
- Firefox GitHub Pages上でDOM→PNG→ZIPを大量ページに対して行う実機確認
- 端末・ブラウザごとのlocalStorage容量差
- 紙面PNG化はブラウザのSVG `foreignObject` 実装に依存する
- アーカイブ済み旧紙面は現状、提出ZIPへPNG再生成せず概要のみ含める

これらは未確認のまま「確認済み」とは扱いません。
