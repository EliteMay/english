# English Worksheet Lab

英語を **「紙の問題集をペンタブで解く → 自分で答え合わせ → 解いた紙をZIPでChatGPTへ渡す → 弱点をサイトへ戻す」** 形で学ぶ個人用サイトです。

友人作成の英語文法ワークシート①〜④を出発点にしていますが、同じ短文を言い換えるだけの反復は減らし、**問題ごとに判断ポイントが変わる**ように再構成しています。

## 目的

- PDF教材のように、1枚の紙へ複数問題を並べて解く
- 入力フォームではなく、ペンタブで問題用紙へ直接書く
- S/V → O/C・5文型 → 動詞の意味 → to/ing → 修飾・節 → 時制 → 前置詞の核イメージ → 長文へ積み上げる
- 基礎から扱うが、簡単な同型問題を大量に繰り返さない
- 長文では訳より先に主節S/V・節・修飾を紙面上で分ける
- 前置詞や基本語は日本語訳だけでなく核イメージで理解する
- 最終結果だけでなく、丸・下線・括弧・矢印・消去・書き直しなど途中の思考を残す
- ChatGPTにはJSONだけでなく、**実際に解いた問題用紙PNG入りZIP**を渡す

## 画面構成

### 1. 問題を選ぶ

問題セットを一覧から選びます。教材系統・難易度で絞り込みできます。

v0.4.1では8セット・106問です。

1. S/Vを本当に見抜く
2. O/C・5文型を関係で判定
3. 同じ動詞でも構造が変わる
4. to / ing をイメージで理解
5. 修飾を外して節を分ける
6. 時制を時間の見え方で選ぶ
7. 前置詞を核イメージで考える
8. 長文を骨格から読む

### 2. 問題を解く

A4風の問題用紙へ、最初から最後までペンタブで直接書き込みます。

- 解答モード切替なし（常時ペン）
- 問題文・英文の上へ直接書ける
- S/V/O/C用の下線欄
- 選択肢へ丸を付ける
- 記述用罫線
- 黒 / 赤 / 青 / 緑
- 筆圧対応
- 消しゴム
- 1ストロークUndo
- ページ単位全消去
- 途中保存

タッチ入力はスクロール用、ペン・マウスを筆記用として扱います。

### 3. 答え合わせ・結果

手書きはサイト内でOCRしません。

「答え合わせへ」を押すと、問題用紙そのものは動かさず、その下に正答基準を表示します。各問題を次の3段階で自己採点します。

- ○ 正解
- △ 一部不安・部分正解
- × 間違い

自由記述・長文の説明問題はChatGPT確認対象です。

## ChatGPT提出ZIP

「ChatGPT提出ZIP」を押すと、書き込みがある問題用紙だけを自動収集してZIPへまとめます。

```text
english_submission_YYYY-MM-DD.zip
├─ papers/
│  ├─ S_Vを本当に見抜く_page01.png
│  └─ ...
├─ learning-data.json
├─ ink-history.json
├─ questions.json
└─ ChatGPTに見てほしいこと.txt
```

### `papers/*.png`

最重要データです。

- 問題文
- 手書き回答
- S/V記号
- 丸
- 下線
- 括弧
- 矢印
- 最終的に残った書き込み

を1枚の問題用紙としてChatGPTへ渡します。

### `ink-history.json`

ペンの生データです。

- ストロークの順番
- 時刻
- 座標
- 筆圧
- ペン色
- 消しゴムストローク
- 関連する問題ID

を保存します。最終PNGでは消えている線でも、`eraser: true` の履歴を含めることで「途中で何を書き、どこを消したか」を分析する補助になります。

### `learning-data.json`

画像だけでは分からない情報を補助します。

- 自己採点
- 過去の結果
- 問題ごとのペンストローク数
- 途中保存履歴
- 利用した問題セット

### `questions.json`

提出した問題の問題文・正答基準です。

### `ChatGPTに見てほしいこと.txt`

ChatGPTに、最終正誤だけでなく「どこをS/Vだと思ったか」「主節と従属節をどう分けたか」「危ない読み方をしていないか」まで見るよう指示します。

## 問題設計方針

### やらないこと

- `I study English.` → `Tom plays tennis.` → `She likes music.` のような同じ構造だけの大量水増し
- 単語だけ置き換えた問題を問題数として数えること
- 5文型を記号暗記だけで判定させること
- 現在完了を用法ラベルの暗記だけで終えること

### 優先すること

- 前置詞句がS候補に見える
- 動詞らしい形が複数ある
- 関係詞節が主節に割り込む
- 分詞・不定詞・動名詞が骨格に見える
- 同じ動詞でも意味により文型が変わる
- OとCの違いを `O=C` で判断する
- 時制を時間軸・視点から選ぶ
- to / from / in / on / at / for を核イメージから考える
- 長文では紙に括弧・下線を書かせ、処理過程を残す

## 崩してはいけない仕様

- サイトの中心は問題を解くこと
- 1問ずつではなく複数問題が紙面に並ぶ
- ペンタブで直接書くことを標準操作にする
- 入力フォーム中心へ戻さない
- 同じ型の単純問題で問題数を水増ししない
- 長文では主節S/V・節・修飾を見る
- 単語・前置詞は核イメージを重視する
- 実際に解いた紙面をChatGPTへ渡せる
- 消した線を含むペン履歴もChatGPT分析の補助に残す
- ChatGPTは結果だけでなく途中の読み方を分析する
- ChatGPT分析結果を弱点ページへ戻せる

## 未確認・既知の課題

- Windows実機ペンタブでの長時間の筆圧・遅延
- Firefox / GitHub Pagesでの問題用紙PNG変換の実機確認
- 非常に大量の手書きを保存した場合のlocalStorage容量
- ZIP内PNGが多い場合は生成に数秒以上かかる可能性がある
