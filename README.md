# English Worksheet Lab

英語を「問題を大量に解く → 結果を見る → ChatGPTに学習過程を渡す → 弱点を戻す」の流れで使う個人学習サイトです。

友人作成の英語文法ワークシート①〜④を出発点に、Web上でPDFワークシートのように問題を解ける構成へ再設計しています。

## 目的

- 問題をたくさん解くことを中心にする
- S/V → SVO → 5文型 → 動詞語法 → 修飾 → 時制 → 長文の順で基礎を積み上げる
- 基礎から扱うが、説明・問題を幼くしない
- 長文では訳より先に主語・動詞・節構造を見る
- 前置詞や基本語は日本語訳だけでなく核イメージで理解する
- 正答率だけでなく、答えを変えた履歴・途中メモ・自信度・ペン書き込みを残す
- 学習JSONをChatGPTへ渡し、判明した弱点をサイトへ戻して見られるようにする

## 画面構成

### 1. 問題を選ぶ

- 問題セット一覧
- 教材①〜④・長文で絞り込み
- 難易度で絞り込み
- 問題数、進捗、前回点数を表示

初版では11セット・144問を収録しています。

### 2. 問題を解く

A4ワークシート風の紙面に10問ずつ表示します。

- キーボード入力
- 選択問題
- 記述問題
- 各問題の途中メモ
- 自信度1〜5
- 答え変更履歴の保存
- ペンタブで問題文・英文の上へ直接書き込み
- 筆圧対応
- 黒 / 赤 / 青 / 緑
- 消しゴム
- 1ストロークUndo
- ページ単位の全消去
- 途中経過スナップショット

ペンモードではCanvasが問題紙面の上に重なり、PDFへ書き込む感覚に近づけています。解答モードに戻すと入力欄や選択肢を操作できます。

### 3. 結果

- 自動採点可能問題の点数
- スキル別正答率
- 各問題の正誤
- 自分の答え
- 正答基準
- 答え変更回数
- 自信度
- ペンストローク数
- 途中メモ
- 過去の受験履歴

記述問題は自動採点せず、ChatGPT分析対象として残します。

### 4. 弱点・ChatGPT分析

学習JSONを書き出してChatGPTへ渡し、返ってきた分析JSONを読み込みます。

表示できる内容:

- 全体所見
- 弱点
- 弱点の原因
- 根拠になった問題・変更履歴
- 弱点の重要度
- 次に優先する項目
- できているところ
- 推奨問題セット

推奨問題セットは弱点カードから直接開始できます。

## ChatGPTへ渡すデータ

`ChatGPT分析用JSON` には以下を含めます。

- 学習方針
- 利用可能な問題セット一覧
- 各受験結果
- 問題文
- 最終回答
- 正答基準
- 正誤
- スキル
- 自信度
- 各回答の変更履歴
- 途中メモ
- 途中保存スナップショット
- ペン書き込み数と関連問題
- ChatGPTへの分析依頼文

ペンストロークの数値座標そのものは大量データになるため、分析用JSONでは要約のみを出力します。実際の手書き内容をAIに読ませたい場合は、将来「注釈付き問題紙面を画像として書き出す」機能を追加する予定です。

## ChatGPTから戻すJSON

サイトが受け付ける基本形式:

```json
{
  "weaknessAnalysisVersion": 1,
  "generatedAt": "2026-08-30T00:00:00+09:00",
  "summary": "全体所見",
  "weaknesses": [
    {
      "id": "w1",
      "title": "主節Vと従属節Vの区別",
      "severity": "high",
      "confidence": 0.9,
      "cause": "原因",
      "evidence": ["根拠"],
      "recommendedPackIds": ["w3-long", "long-reading"]
    }
  ],
  "strengths": [
    {"title": "SVOの基本", "note": "短文では安定"}
  ],
  "nextTargets": ["次に行うこと"]
}
```

## データ保存

学習データはブラウザの `localStorage` に保存します。

キー:

```text
english-worksheet-lab-v2
```

個人の成績やメモをGitHubへ自動送信することはありません。

## GitHub Pages

HTML / CSS / JavaScript / JSON の静的構成なのでGitHub Pages対応です。

リポジトリの Settings → Pages から `main` / `/ (root)` を公開対象にしてください。

## ファイル構成

```text
/
├─ index.html
├─ css/
│  └─ styles.css
├─ js/
│  ├─ core.js
│  ├─ practice.js
│  ├─ results-analysis.js
│  ├─ ink.js
│  └─ bootstrap.js
├─ data/
│  └─ packs/
│     ├─ index.json
│     └─ packs-1.json ～ packs-6.json
├─ README.md
└─ 作業報告書.md
```

旧版のデータJSONや補助ファイルがリポジトリに残っている場合がありますが、新版では参照していません。安全のため削除せず保持しています。

## 崩してはいけない仕様

- 問題を解くことがサイトの中心
- 1問ずつではなく複数問題が1枚の紙面に並ぶ
- ペンタブで問題文・英文へ直接書ける
- S/Vや節構造を見る長文問題を含める
- 最終結果だけでなく途中の思考過程を保存する
- 記述・途中メモをChatGPT分析対象にする
- ChatGPT分析結果をサイトへ戻して弱点として見られる
- 英語を暗記だけで教えず、本質・構造・核イメージを重視する
