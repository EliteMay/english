# English Worksheet Lab

**Version: v0.5.2**  
**Build: 20260830-4**  
**Data Schema: 4 / Analysis Schema: 2 / Submission Package: 2**

英語を **「PDFのような問題用紙へペンタブで直接解く → 自分で答え合わせ → 解いた紙をZIPでChatGPTへ渡す → 弱点をサイトへ戻す → 問題集自体を弱点に合わせて更新する」** 形で学ぶ個人用GitHub Pagesサイトです。

## 目的

- 紙の教材のように1ページへ複数問題を並べる
- 入力フォームではなく、問題文の上へ直接書く
- S/V → O/C・文型 → 動詞 → to/ing → 節 → 時制 → 語順 → 誤文修正 → 長文・段落へ積み上げる
- 基礎から扱うが、同型の簡単問題を大量反復しない
- 長文は逐語訳より先に主節S/V・節境界・修飾・論理関係を見る
- 前置詞・基本語は日本語訳1語より核イメージを重視する
- 最終正誤だけでなく、丸・下線・括弧・矢印・消去・書き直し・時間を残す
- ChatGPT分析で繰り返し見えた弱点は、専用補強問題へ反映する

## v0.5.2 — 答え合わせを左右2ペイン化

答え合わせ時の見づらさを改善しました。

デスクトップでは:

- **左:** 実際に解いた問題用紙
- **右:** 正答基準・○△×・迷いタグ・メモ

を同時に表示します。

右の答え合わせ欄は独立スクロールするため、正答を下まで確認しても左の問題用紙はその場に残ります。問題用紙側も必要な場合だけ独立してスクロールできます。

1024px未満の狭い画面では無理に2列へせず、従来の上下配置へ戻します。

ペン座標・紙面PNG・ChatGPT提出ZIPの形式は変更していません。

## v0.5.1 — 最初の実提出ZIPから改善

最初の `english_submission_2026-08-30.zip` を実際に分析して、次を修正しました。

### 学習上の発見

問4〜9で、S/Vを「1語だけ」に縮める傾向が連続して確認されました。

例:

- `was found` → `was` だけをVにする
- `is waiting` → `is` だけ
- `were waiting` → `were` だけ
- `has been checked` → `has` だけ
- `Running every morning` → `Running` だけをSにする
- `To understand the rule` → `To understand` までをSにする

そのため専用セット **「補強｜S/Vを1語ではなく『かたまり』で取る」12問** を追加しました。

このサイトでは構造分析上、

- **S** = 主語として働く語句・節の範囲全体
- **V** = be / have / 助動詞 + 分詞など、進行・受動・完了を作る動詞のまとまり

として扱います。

### スコア計算修正

以前は1ページだけ解いて結果を保存すると、まだ解いていない次ページまで0点扱いになる問題がありました。

v0.5.1からは:

- 未着手問題は0点にしない
- 解いた範囲だけで今回スコアを計算
- 未着手問題は理解度・ミス復習へ混ぜない
- 全問終わっていないセットは「完了」にしない

ように変更しました。

## 現在の問題集

**15セット / 200問**

1. S/Vを本当に見抜く
2. **補強｜S/Vを1語ではなく『かたまり』で取る**
3. O/C・5文型を関係で判定
4. 同じ動詞でも構造が変わる
5. to / ing をイメージで理解
6. 前置詞を核イメージで考える
7. 前置詞の核イメージを広げる
8. 修飾を外して節を分ける
9. 時制を時間の見え方で選ぶ
10. 語順から英文の骨格を組み立てる
11. 誤文修正｜なぜ不自然かを見抜く
12. 構造トラップ｜Vっぽい形を全部Vにしない
13. 総合診断｜どこで判断が崩れるか
14. 長文を骨格から読む
15. 段落読解｜骨格・指示語・論理を追う

## カリキュラム

1. **骨格を取る** — S/V、S/Vの範囲、O/C・5文型
2. **動詞とイメージ** — 動詞の意味、to/ing、前置詞の核イメージ
3. **節と時間** — 修飾・節、時制
4. **構造を使う** — 語順、誤文修正、構造トラップ、総合診断
5. **長文へ統合** — 一文構造、段落の因果・対比・指示語・要約

## 画面

### 01 問題を選ぶ

- 分野・難易度・進捗で絞り込み
- フリーワード検索
- 5段階カリキュラム
- 続きから
- ChatGPT分析からの推奨問題
- △・×から作るミス復習
- 目安時間

### 02 問題を解く

A4風の問題用紙へ常時ペン入力します。

- 問題文の上へ直接書く
- 黒 / 赤 / 青 / 緑
- 蛍光マーカー
- 細 / 中 / 太
- 筆圧
- 消しゴム
- Undo / Redo
- ページ全消去 + Undo
- 85 / 100 / 115 / 130%用紙倍率
- 集中モード
- ページ学習時間
- 途中状態スナップショット

タッチ入力はスクロール、ペン・マウスを筆記に使います。

#### 答え合わせ

デスクトップでは問題用紙を左、採点欄を右に固定した2ペイン表示になります。

- 左右は独立スクロール
- 右で正答・採点・迷いタグ・メモを処理
- 左の手書き問題用紙を見失わない
- 狭い画面では上下配置

### 03 結果・復習

- ○ / △ / × 自己採点
- 迷いタグ・自由メモ
- 分野別最新理解度
- 学習時間
- 履歴
- ミス復習
- 未着手はスコア・ミス復習から除外

### 04 弱点・ChatGPT分析

ChatGPTから返された分析JSONで:

- 弱点 / 原因 / 根拠 / 確信度
- 分野別AI評価
- 読み方の癖
- 強み
- 次の学習対象
- 推奨問題セット
- サイト自体への改善提案
- 分析履歴

を表示します。

## 崩してはいけない仕様

1. サイトの中心は「紙の問題集を解く」こと
2. 1問ずつではなく複数問題を紙面に並べる
3. ペンタブで直接書く
4. 入力フォーム中心へ戻さない
5. 同型問題で水増ししない
6. 基礎でも幼すぎる説明にしない
7. S/Vは語だけでなく働く範囲・まとまりを見る
8. 長文は主節S/V・節・修飾・論理を見る
9. 単語・前置詞は核イメージを重視
10. 解いた紙面をChatGPTへ渡せる
11. 消した線を含む途中経過を残す
12. ChatGPT分析をサイトと次の問題へ反映する
13. 未着手問題を誤答扱いしない
14. 学習データを公開GitHubへ自動送信しない
15. 破壊的操作には復旧手段を用意する
16. GitHub Pagesの相対パスを維持する
17. 答え合わせでは問題用紙と正答欄を同時に見られること
