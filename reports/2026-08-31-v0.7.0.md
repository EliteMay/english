### 4. Diagnostics Privacy / Security

Diagnosticsは学習履歴やAnalyticsではなく、不具合調査用のLocal Runtime Evidenceとした。

自動記録しないもの:

- 学習回答本文
- 手書きStroke
- 問題用紙画像
- Import File本文
- Token / Password / Cookie / API Key
- Binary

文字列はURL query / fragmentと代表的Secret形式をSanitizeする。

`handoff` safe default:

```text
sanitized = true
remoteEligible = false
containsBinary = false
containsSecrets = false
```

Remoteへの自動送信Codeは追加していない。

### 5. データ管理UI

追加:

- 開発診断件数 / Error件数Summary
- 「開発診断JSON」Download
- 「診断ログ消去」

診断Log削除は学習Data、Paper Snapshot、Ink、Resultへ影響しない。

### 6. 学習Handoffとの分離

ChatGPT提出ZIPは削除しない。

理由:

- 手書きの丸・下線・括弧・実際の紙面が学習分析の主要Evidence
- Runtime DiagnosticsのCompact JSONではBinary / Visual Evidenceを代替できない

用途を以下に分離した。

```text
学習の弱点分析 → ChatGPT提出ZIP
サイトの不具合調査 → 開発診断JSON
長期の再発防止 → PROJECT_LEARNINGS.md
```

### 7. Remote Diagnostic Handoff判断

今回は導入しない。

理由:

- Core機能はGitHub Pagesだけで成立
- 外部Providerを追加する必要性がまだない
- Free-only条件、Provider pause / quota / securityを新しい必須依存へしない
- Binary学習EvidenceはどのみちZIPが必要

将来導入する場合もLocal DiagnosticsをFallbackとして維持する。
